# Guessing Games

Two simple python projects: a Number Guessing Game and a Word Guessing Game.

# Number Guessing Game
Enter a lower and upper bound, the computer will randomy select a number in that range
Try to guess the number while receiving hints, you have a limited number of guesses based on range size

# Word Guessing Game
A random word is selected from a list, guess one letter at a time
Correct letters are revealed in the word, you are given 12 turns to guess the word
